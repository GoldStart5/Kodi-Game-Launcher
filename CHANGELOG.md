# Changelog

## Addon updates since 3.0.0

- **Game Launcher 1.7.1:** new options to minimise Kodi after it has been out of focus for a set time (to save GPU while a game runs), and to bring Kodi back when the game closes.
- **Cinema Themes 1.2.5:** the normal fade-in and fade-out can now be set up to 10000 ms. The switch fades stay at 5000 ms at most.
- **Cinema Themes 1.2.4:** root themes now have their own order, loop and random start settings, and every setting has a description.
- **PS2 Overlays 1.1.2:** new light sweep animation with its own on/off switch and settings (colour, opacity, speed, size, position and drift), and an option to make the current hour bar of the clock shine.
- **PS2 Overlays 1.0.2** added to the repository: transparent PlayStation 2 style clock, cubes and rings overlays for the Kodi home screen, each with its own on/off switch and settings.
- **Cinema Themes 1.2.3:** new toggles for the root theme, for the global theme replacing a missing root theme, and for hovering an item to play its own theme.
- **Cinema Themes 1.2.2:** on/off switch for the global theme.
- **Cinema Themes 1.2.1:** going from the global theme to a library theme uses the switch fades.
- **Cinema Themes 1.2.0:** a global theme folder replaces the old fallback root theme settings. It plays outside the library and whenever no other theme applies, with its own order, loop, random start and resume options. If you used the old root theme settings, set up the global theme folder instead.
- **Theme & Trailer Grabber 1.0.5** added to the repository: search YouTube for a movie or show's theme or trailer and download it into the title's folder.
- **Cinema Themes 1.1.1:** a show keeps its theme after you leave its seasons or episodes, until another show is focused.
- **IGDB + SteamGridDB Game Scraper 1.3.1:** new defaults. IGDB artworks and screenshots are now added to the fanart list, with 25 slots reserved for them and a maximum of 50 fanart images.
- **Game Launcher 1.6.3:** faster start of a launch. The splash appears sooner because slow library lookups no longer run before it is on screen.
- **Game Launcher 1.6.1:** new "Splash zoom style" setting (zoom in then out, zoom out then in, or random).
- **Cinema Themes 1.1.0:** separate fades when one theme switches to another, a hovered movie or show plays its own theme when there is no root theme, and a movie keeps its theme after its info dialog closes.
- **Cinema Themes 1.0.4** added to the repository: theme music for movie and show folders, played with mpv.
- **Repository 1.0.1:** new icon, and Cinema Themes is listed.
- **IGDB + SteamGridDB Game Scraper 1.3.0:** new "SteamGridDB fanart size" setting (3840x1240 by default, 1920x620 or both), with IGDB images used when no hero matches. Optionally mix IGDB artworks and screenshots into the fanart list, with reserved slots.
- **Game Launcher 1.5.0:** new "Show splash before launching the game" time (1 to 7 seconds), a "Longest wait for the game to open" timeout, and an option to update "Last played" when a game launches while keeping it unwatched. The fanart zoom setting was removed.

## 3.0.0

- **Playnite and the Playnite Kodi Exporter are no longer needed.** Metadata and artwork now come from the IGDB + SteamGridDB Game Scraper.
- AutoHotkey and the MPV player rule are no longer needed. The Game Launcher service handles everything inside Kodi.
- Both addons are now installed and updated through the Kodi Game Launcher Repository.
- Guides rewritten for the new setup.

Included addons:

- IGDB + SteamGridDB Game Scraper 1.2.1
- Game Launcher 1.2.0
- Kodi Game Launcher Repository 1.0.0
